# Data

The measurements the manuscript's figures are drawn from, the plotter that draws them, and the
notebook that produced the published versions.

| | |
|---|---|
| `<YYYYMMDD>/` | one sweep's samples, one CSV per cell |
| `<YYYYMMDD>/figures/` | one PNG per CSV, generated by `make` |
| [`data-main-text/`](data-main-text/) | `sw-for-loop` RTT traces used in the main text |
| [`data-appendix/`](data-appendix/) | `hw-for-loop` RTT traces used in the appendix |
| [Makefile](Makefile) | draws every figure that is missing or out of date |
| [plot_latency.py](plot_latency.py) | the plotter: latency over time, and a histogram of the same samples |
| [LatencyPlots.ipynb](LatencyPlots.ipynb) | round-trip latency distributions per cell |

## Drawing the figures

```bash
cd data
make                     # every figure that is missing, or whose CSV or plotter changed
make main-text           # figures from data-main-text/
make appendix            # figures from data-appendix/
make list                # what would be drawn, and with which plotter
make clean               # remove every figures/ directory
make FLAGS='--logy'      # override the plotting flags for this run
```

A figure depends on its CSV and on the script that drew it, so editing the plotter redraws the
figures rather than leaving them stale. A dataset that keeps its own `plot_latency.py` is drawn with
that one, which is how an archived result stays reproducible after the shared script moves on.

## The CSVs

Written by [`../benchmarks/bench.py`](../benchmarks/bench.py), one file per cell, named
`rtt_<coproc>_<ctrl>.csv`. The columns are `sample`, `rtt_cycles` and `rtt_us`, with the clock and
the cell recorded in two comment lines at the top of each file.
[`../scripts/sweep-bench.sh`](../scripts/sweep-bench.sh) writes a whole matrix at once, into a
directory that becomes one dataset here.

A dataset directory is named `YYYYMMDD`, which is the shape the Makefile matches. A sweep directory
carries a time as well, so `sweep-20260819-174612` becomes `20260819` and the time is recorded here.

## RTT datasets

The five `sw-for-loop` traces used by the manuscript live in `data-main-text/`. The appendix inputs
live in `data-appendix/`: ten `hw-for-loop` traces split between the `b2b` and `random-delayed`
cadences. Each directory has its own README with naming, pacing parameters, figure commands, and
reproduction instructions.
